🥗 Vittle Healthy Foods Website

A modern, responsive healthy food & organic products website built using React.js.
This platform showcases a variety of natural food items such as millets, spices, dry fruits, and seasonings with a clean UI and smooth user experience.

🚀 Live Demo

👉 https://vittle-healthy-foods.vercel.app/

📌 Project Overview

Vittle Healthy Foods is a frontend web application designed to promote healthy eating habits by presenting organic and natural food products in an attractive and user-friendly interface.

The website focuses on:

Clean UI/UX
Fast performance
Mobile responsiveness
Product showcasing
✨ Features
🖥️ Fully responsive design (Mobile, Tablet, Desktop)
🥦 Display of healthy food products:
Millets
Spices (Red Chillies, Green Pepper, Coriander, etc.)
Curry powders & mixed masalas
Dry fruits (Dates, Cassia, Celery seeds, etc.)
⚡ Fast loading with optimized React components
🎯 Clean navigation and structured layout
🎨 Modern UI with attractive visuals
🛠️ Tech Stack
Frontend
⚛️ React.js
🎨 CSS / Tailwind CSS (or your styling choice)
🧩 JavaScript (ES6+)
Deployment
▲ Vercel
🧠 How It Was Built (Architecture)

The application follows a component-based architecture using React:

1. Component Structure
Navbar Component – Navigation across pages
Home Component – Landing page with hero section
Product Components – Display categories and items
Footer Component – Developer credits and info
2. React Concepts Used
Functional Components
Props for passing product data
Reusable UI components
Conditional rendering (if used)
Component-based folder structure
3. Styling Approach
Responsive layouts using Flexbox/Grid
Clean spacing and typography
Image-based product representation
4. Deployment Flow

Build React app

npm run build
Push code to GitHub
Connect repository to Vercel
Automatic deployment via CI/CD

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/Cherry2703/vittle-foods-dubai.git

Navigate to project:

cd vittle-foods-dubai

Install dependencies:

npm install

npm start
